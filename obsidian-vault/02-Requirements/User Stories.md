# User Stories

## Planning Engineer
- **US-01**: As a planning engineer, I want to upload WTG coordinates and cadastral parcel files so that I can automatically compute optimal evacuation routes.
- **US-02**: As a planning engineer, I want to compare "Minimum Cost" vs "Minimum Land Impact" scenarios to select the best tradeoff for project stakeholders.

## Electrical Engineer
- **US-03**: As an electrical engineer, I want automated voltage drop and power loss calculations for each feeder line so that I can verify thermal and voltage compliance.

## GIS Specialist
- **US-04**: As a GIS specialist, I want to view slope heatmaps and parcel boundary intersections directly on an interactive map.
