## What I Built Today

### Overview
Implemented the foundational GIS modules in the Python optimizer service (`optimisation-python/app/gis/` and `app/models/`). This allows the system to take raw WGS84 GeoJSON files and robustly convert them into structured spatial data classes with dynamically assigned metric (UTM) coordinates.

### Key Additions
1. **Coordinate Reference System (CRS) Management (`crs.py`)**
   - Automatically detects the ideal UTM zone for the project based on geographic center using `pyproj`.
   - Safely transforms coordinates back and forth between EPSG:4326 and EPSG:326xx.

2. **Geometry Validation & Parsing (`geometry.py` & `geojson.py`)**
   - Validates shapes natively with `shapely`.
   - Repairs self-intersecting anomalies (e.g. bowties) via `make_valid`.
   - Consumes FeatureCollections and strips out standard Shapely Geometries.

3. **Input Preprocessing (`preprocessing.py`)**
   - Ingests multiple WTGs and a Substation.
   - Enforces Point geometries strictly.
   - Extracts all features into our strongly-typed `ProjectSpatialData`, `WindTurbine`, and `Substation` dataclasses defined in `spatial.py`.
