# Frontend Architecture

Source Code:
`frontend/`

## Tech Stack
- **Framework**: Modern Web App (Vite / React or Vanilla JS Web GIS)
- **Mapping Library**: MapLibre GL / Leaflet with GeoJSON vector tile support
- **UI Components**: Modern CSS / Glassmorphism Design System

## Features
- **Interactive Layer Control**: Toggle elevation heatmaps, forest polygons, parcel boundaries, and proposed lines.
- **Scenario Comparison View**: Side-by-side comparison matrix for cost, land impact, and electrical performance.
- **Explainability Drawer**: Breakdown panel explaining route penalties and pole type choices.
