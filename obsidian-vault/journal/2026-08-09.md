## What I Built Today

### 1. Web-Map GeoJSON Ingestion & Leaflet Engine Fixes
- **Script Load Order & Global L**: Moved Leaflet CDN `<script>` tag into `<head>` in `index.html` before the application module bundle, guaranteeing global `L` is initialized prior to `SurgeMapEngine` execution.

### 2. Gujarat Kutch Benchmark GIS Datasets (`web-map/public/data/`)
Created four production-grade GeoJSON test datasets centered on the high-wind Gujarat Kutch corridor:
- `wtgs_kutch.geojson`: 40 WTG points (2.5–4.2 MW ratings, 100–120m hub heights).
- `substations_kutch.geojson`: 3 Substation terminals (Mundra, Kutch North, Bhachau; 33/132 kV).

- `restricted_kutch.geojson`: 8 exclusion zones (Flamingo Sanctuary buffer, Rapar village setback, Narayan Sarovar forest reserve, Bhuj radar buffer).

### 4. 33kV End-to-End Routing Pipeline Architecture
Documented the five-phase data pipeline from UI parameter input to PostGIS persistence:
1. **Phase 1 (UI Dispatch)**: User configures parameters (Scenario, Feeder Capacity, Max Span) and subscribes to SSE stream.
2. **Phase 2 (Java Dispatch)**: `OptimizationJobService` fetches PostGIS spatial assets and dispatches JSON payload.
3. **Phase 3 (Python Solver)**: MILP turbine grouping (`wtg_grouping.py`) + NetworkX metric distance graph + Kruskal Minimum Spanning Tree topology (`topology.py`).
4. **Phase 4 (Persistence)**: `RouteService` persists LineString feeder geometries and MultiPoint pole coordinates into `generated_routes`.
5. **Phase 5 (Map Visualization)**: Leaflet renders feeder lines and updates live Bill of Materials dashboard.
