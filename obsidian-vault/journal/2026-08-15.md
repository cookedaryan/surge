## What We Built Today

### 1. Enterprise Security Hardening & Secret Management
- **Mandatory Environment Secret**: Enforced `APP_JWT_SECRET` environment variable requirement in `SecurityConfig` and `JwtTokenProvider`. Removed all insecure fallback keys and hardcoded demo secrets. The backend now immediately refuses to boot if a secure secret is not injected.
- **Database-Backed Account Verification**: Updated `JwtAuthenticationFilter` to validate user account status against PostgreSQL on every incoming request.
- **Token Invalidation on Credential Change (Flyway V13)**: Added `last_credentials_change` timestamp column to the `users` table (`V13__add_last_credentials_change.sql`). Any password reset, suspension, or credential alteration immediately invalidates previously issued JWT tokens by checking token issue timestamps (`iat`) against the database timestamp.
- **Removal of Default Demo Seeding**: Removed unauthenticated mock user seeding from startup routines to adhere to enterprise zero-trust principles.

### 2. Result Commit Visibility Bug Fix (`completeAfterCommit`)
- **Race Condition Root Cause**: Discovered a critical race condition where the asynchronous worker thread dispatched a Server-Sent Events (SSE) `COMPLETED` terminal message to the browser before the enclosing Hibernate transaction had finished writing `generated_routes` and `MultiPoint` pole entities to PostgreSQL. When the frontend immediately called `GET /api/v1/projects/{projectId}/routes/latest`, it received an empty array or 404.
- **Resolution via Spring Synchronization**: Integrated Spring's `TransactionSynchronizationManager.registerSynchronization` with an explicit `afterCommit` hook:
  ```java
  TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
      @Override
      public void afterCommit() {
          sseProgressService.sendProgress(jobId, 100, "COMPLETED", "Optimization complete");
      }
  });
  ```
  Guarantees that the frontend is notified only after all spatial entities are committed and fully visible to subsequent read transactions.

### 3. Asynchronous Optimization Engine & Background Sweeper
- **Dedicated Thread Pool**: Configured `ThreadPoolTaskExecutor` with dedicated core/max thread pools, queue capacity limits, and custom thread naming (`surge-opt-worker-%d`) to prevent HTTP connection starvation during long-running graph computations.
- **Resilient SSE Progress Stream**: Enhanced `SseProgressService` with automatic reconnect buffering and client disconnection cleanup.
- **Stale Job Sweeper**: Implemented `StaleJobSweeper` scheduled task running periodically to transition orphaned `RUNNING` jobs (e.g., from container restarts or network timeouts) to `FAILED` status with structured diagnostic error logs.

### 4. Four Distinct Operational Scenario Profiles (`ScenarioProfile`)
- Implemented real operational biasing in the Java backend and Python solver:
  1. `BALANCED_DEFAULT`: Equal weighting across CAPEX, electrical loss OPEX, and environmental disruption.
  2. `CAPEX_MINIMIZED`: Aggressive line-length minimization and minimal angle-pole deflection.
  3. `LOSS_MINIMIZED`: Conductor oversizing and short-path bias minimizing operational $I^2R$ power losses.
  4. `ENVIRONMENTAL_FIRST`: High avoidance penalties for cadastral parcel crossings, road intersections, and restricted conservation buffers.
- Verified against field survey ground-truth data from the Uravakonda 33kV wind farm collector network.
- Implemented 17 dedicated mutation and boundary tests in `ScenarioProfileTest`.

### 5. Admin Panel, Account Management & Audit Logging
- **User Administration Controller (`/api/v1/admin/users`)**:
  - Full administrator management suite: user listing, account suspension (`V11__add_user_suspension.sql`), password resets, and role modifications (`ROLE_ADMIN`, `ROLE_PLANNER`, `ROLE_VIEWER`).
  - Implemented admin lockout protection invariants preventing administrators from demoting or suspending their own active accounts.
- **Enterprise Audit Trail (`AuditLogService`, `/api/v1/audit-logs`)**:
  - Implemented `AuditLogService` using `Propagation.REQUIRES_NEW` to ensure audit records are written independently even if parent business transactions fail.
  - Automatically captures actor username, IP address, timestamp, action type (`PROJECT_CREATE`, `ASSET_IMPORT`, `OPTIMIZATION_RUN`, `REPORT_EXPORT`), entity target, and JSON change payload.

### 6. Engineering Data Correctness & Unit Conversions
- **Real AC Loss Calculation**: Fixed active loss reporting in `ReportService` and BOM aggregations to correctly reflect Pandapower Newton-Raphson real AC losses ($kW$), eliminating an order-of-magnitude unit conversion discrepancy ($kW$ vs. $MW$).
- **Geometric Right-of-Way (ROW) Parcel Intersections**: Implemented `app/gis/row_analysis.py` using Shapely polygon clipping to calculate exact corridor parcel intersection areas ($m^2$) and variable compensation line items, replacing linear estimate heuristics.

### 7. Modern Frontend Enhancements (`web-map-next`) & WCAG Accessibility
- **Leaflet Performance Upgrade**: Configured Leaflet with `preferCanvas: true` renderer, enabling 60 FPS smooth zooming and panning when rendering 600+ pole markers and complex multi-feeder LineStrings.
- **WCAG 2.1 AA Compliance**: Improved contrast ratios across dark mode theme, standardized minimum $44\text{px} \times 44\text{px}$ touch targets, and established a consistent typography scale.
- **Authorized Report Blob Downloads**: Replaced insecure `window.open` URL downloads with an authenticated `fetch + blob` download handler that injects JWT `Authorization: Bearer <token>` headers when exporting executive PDF and CSV reports.
