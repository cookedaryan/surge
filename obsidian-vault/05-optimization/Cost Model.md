# Lifecycle Cost Objective Model

## Cost Equation

$$\text{Total Cost} = \text{CAPEX}_{\text{poles}} + \text{CAPEX}_{\text{conductor}} + \text{CAPEX}_{\text{ROW}} + \text{OPEX}_{\text{losses}}$$

Where:
- $\text{CAPEX}_{\text{poles}}$ = Pole unit cost $\times$ count + foundation cost (slope dependent).
- $\text{CAPEX}_{\text{conductor}}$ = Conductor length $\times$ cost per meter.
- $\text{CAPEX}_{\text{ROW}}$ = Parcel compensation area $\times$ rate per $m^2$.
- $\text{OPEX}_{\text{losses}}$ = Present value of lifetime $I^2R$ power losses.
